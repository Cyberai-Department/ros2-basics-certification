# ROS 2 JAZZY Course Certificates Repository

## Description
This repository contains the official certificates of students who successfully completed the ROS 2 JAZZY course.

Each student has:
- A PDF certificate
- A digital certificate link for online verification

## About the Course
ROS 2 JAZZY is a hands-on robotics course focused on the Robot Operating System (ROS 2). It introduces core concepts such as nodes, topics, services, and system communication, enabling students to build real-world robotic applications.

## Course Details
- Course Name: ROS 2 JAZZY
- Course Duration: 8 weeks
- Days: Saturday & Wednesday
- Number of Workshops: 12 workshops
- Workshop Duration: 2 hours
- Date: 9/2/2026 - 9/4/2026

## Contents
- PDF for Students certificates 
- general link for Digital certificate : https://cyberai-department.github.io/ros2-basics-certification/index.html
